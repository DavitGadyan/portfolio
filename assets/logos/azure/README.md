# Azure architecture icons

Official Microsoft product icons, copied unchanged from the Azure Architecture Center icon set
(https://learn.microsoft.com/en-us/azure/architecture/icons/, `Azure_Public_Service_Icons_V25.zip`, November 2026 batch):

| file | icon in the set |
| --- | --- |
| `foundry.svg` | ai + machine learning / 035746832-icon-service-AI-Foundry.svg (Microsoft Foundry) |
| `azure-ai-search.svg` | ai + machine learning / 10044-icon-service-Cognitive-Search.svg (Azure AI Search) |
| `document-intelligence.svg` | ai + machine learning / 00819-icon-service-Form-Recognizers.svg (Azure AI Document Intelligence) |
| `data-factory.svg` | analytics / 10126-icon-service-Data-Factories.svg (Azure Data Factory) |

Terms (from the same page): "Microsoft permits the use of these icons in architectural diagrams, training materials, or
documentation." They are used here only to depict those Microsoft products, next to their names, never cropped, rotated
or recoloured. `scripts/prepare-logos.mjs` copies them to `public/logos/`. The Microsoft Fabric mark comes from the MIT
licensed npm package `@fabric-msft/svg-icons` instead (fetched by the same script).

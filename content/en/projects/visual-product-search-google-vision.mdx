## The problem

The client wanted to find, for any photo of a clothing item, the products in a reference catalogue that look most like it. Doing that by eye across a large catalogue is slow, and building and training a custom similarity model from scratch was more than the project needed. Google Cloud's Product Search API already does the heavy lifting, so the job was to put a usable service around it.

## What I built

- A service in Python that accepts a list of images as input rather than a single upload, so a whole batch can be processed in one run.
- The integration with the Google Cloud Vision Product Search API, which matches each input image against the client's reference product images.
- Result handling that keeps the top 10 visually similar products for each input image.
- An Excel export with one block of results per product, so the client can review the matches in a spreadsheet.

## Outcome

The client submits a batch of clothing images and receives an Excel file with the ten closest catalogue matches for each one. The service runs on Google Cloud and reuses the Product Search API instead of a custom-trained model.

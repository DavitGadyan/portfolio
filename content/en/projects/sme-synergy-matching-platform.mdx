## The problem

The client wanted a web platform where small and medium-sized enterprises could be matched on how much synergy they would create together, with the score coming from an AI model rather than from a manual assessment. It had to be a real, hosted web application that users could open in a browser, not a notebook or a spreadsheet.

## What I built

- A React web application that presents each business and its synergy scores.
- A custom scoring algorithm that calculates synergy between SMEs, using a machine learning model as its core.
- The wiring between the front end and the scoring logic so the scores appear in the interface.
- Deployment of the application to Vercel, giving the client a live, publicly reachable platform.

## How it was delivered

I built the platform as a single product rather than a model plus a separate interface: the React app and the scoring algorithm were developed together and shipped to Vercel as one deployment, so the client could share a URL and start testing straight away.

## Outcome

A live AI matching platform that scores synergy between SMEs through a custom ML-backed algorithm, built in React and running on Vercel. The client has a working product to put in front of users rather than a prototype.

## The problem

The client needed to turn web pages into structured information quickly: paste a URL, get back a summary and a fixed set of key details the client cared about, in a format that opens in a spreadsheet. Reading each page and copying the details by hand did not scale, and a generic summariser would not return the specific fields the client wanted.

## What I built

- A Python Dash web application with a single input field for the URL.
- A scraping step that fetches the page and pulls out its content.
- An integration with the ChatGPT API that summarises the scraped content and extracts the key details the client specified, so the output follows those fields rather than a free-form summary.
- A clean results table in the app, downloadable as an Excel file.

## Outcome

A URL-in, structured-summary-out tool: the client pastes a link, the app scrapes it, ChatGPT summarises it against the agreed list of key details, and the result lands in a table that can be downloaded as Excel. One small web app replaced manual reading and copying.

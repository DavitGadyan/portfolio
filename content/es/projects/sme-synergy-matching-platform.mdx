## El problema

La clienta quería una plataforma web en la que las pequeñas y medianas empresas pudieran emparejarse según la sinergia que crearían juntas, con una puntuación que saliera de un modelo de IA y no de una valoración manual. Tenía que ser una aplicación web real y alojada, que los usuarios pudieran abrir en el navegador, no un notebook ni una hoja de cálculo.

## Qué construí

- Una aplicación web en React que presenta cada empresa y sus puntuaciones de sinergia.
- Un algoritmo de puntuación a medida que calcula la sinergia entre pymes, con un modelo de machine learning como núcleo.
- La conexión entre el frontend y la lógica de puntuación para que las puntuaciones aparezcan en la interfaz.
- El despliegue de la aplicación en Vercel, que da a la clienta una plataforma en producción y accesible públicamente.

## Cómo se entregó

Construí la plataforma como un único producto y no como un modelo más una interfaz aparte: la app en React y el algoritmo de puntuación se desarrollaron juntos y se enviaron a Vercel como un solo despliegue, de modo que la clienta pudiera compartir una URL y empezar a probar de inmediato.

## Resultado

Una plataforma de matching con IA en producción que puntúa la sinergia entre pymes mediante un algoritmo a medida respaldado por ML, construida en React y funcionando en Vercel. La clienta tiene un producto operativo que poner delante de los usuarios, no un prototipo.

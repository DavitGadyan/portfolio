## El problema

Equeum (antes Machina Software) quería ver si la atención y el ánimo del público respecto a una acción se movían con su precio. El interés de búsqueda y el sentimiento viven en API distintas, así que un analista tenía que extraer cada fuente a mano antes de poder comparar nada. La petición era una interfaz web en la que alguien elige un ticker y ve de inmediato tendencias, sentimiento y cómo se relacionan.

## Qué construí

- Un dashboard web en el que el usuario selecciona un ticker de una lista de valores soportados.
- Dos aplicaciones separadas por detrás: una obtiene las últimas tendencias de búsqueda de esa acción desde la API de Google Trends y la otra recoge sus puntuaciones de sentimiento de varias API de sentimiento.
- Un conjunto de gráficos que alinean ambas series y muestran correlaciones y patrones recurrentes entre el sentimiento y la tendencia de cada valor.
- Una capa de análisis de Reddit que relaciona cambios de precio y rentabilidades con el sentimiento público hacia acciones concretas, construida en torno al episodio de GameStop.
- Python de principio a fin, desde los clientes de las API hasta el análisis de correlación que alimenta los gráficos.

## Datos e infraestructura

El valor de la herramienta está en unir fuentes que nunca se diseñaron para unirse: series de Google Trends, puntuaciones de varios proveedores de sentimiento, publicaciones de Reddit e histórico de precios. Cada fuente se obtiene por ticker y se representa junto a las demás, de modo que las vistas de correlación comparan series comparables y no feeds en bruto y separados.

## Resultado

Equeum obtuvo dos aplicaciones enlazadas que convierten la selección de un ticker en series de tendencia y sentimiento con gráficos de correlación, además de un estudio de Reddit que muestra cómo el sentimiento público siguió los movimientos de precio y las rentabilidades de meme stocks como GameStop.

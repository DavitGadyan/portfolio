## El problema

El cliente necesitaba convertir páginas web en información estructurada con rapidez: pegar una URL y recibir un resumen y un conjunto fijo de datos clave que le interesaban, en un formato que se abriera en una hoja de cálculo. Leer cada página y copiar los datos a mano no escalaba, y un resumidor genérico no devolvería los campos concretos que el cliente quería.

## Qué construí

- Una aplicación web en Python Dash con un único campo de entrada para la URL.
- Un paso de scraping que descarga la página y extrae su contenido.
- Una integración con la API de ChatGPT que resume el contenido extraído y saca los datos clave especificados por el cliente, de modo que la salida sigue esos campos y no un resumen libre.
- Una tabla de resultados limpia dentro de la app, descargable como archivo Excel.

## Resultado

Una herramienta de URL de entrada y resumen estructurado de salida: el cliente pega un enlace, la app hace scraping, ChatGPT lo resume según la lista acordada de datos clave y el resultado aparece en una tabla que puede descargarse en Excel. Una pequeña aplicación web sustituyó la lectura y el copiado manuales.

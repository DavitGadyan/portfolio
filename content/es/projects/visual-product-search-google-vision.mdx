## El problema

El cliente quería encontrar, para cualquier foto de una prenda, los productos de un catálogo de referencia que más se le parecen. Hacerlo a ojo sobre un catálogo grande es lento, y construir y entrenar un modelo de similitud propio desde cero era más de lo que el proyecto necesitaba. La API Product Search de Google Cloud ya hace el trabajo pesado, así que la tarea consistía en montar un servicio utilizable alrededor de ella.

## Qué construí

- Un servicio en Python que acepta como entrada una lista de imágenes en lugar de una sola subida, de modo que un lote completo se procesa en una ejecución.
- La integración con la API Vision Product Search de Google Cloud, que compara cada imagen de entrada con las imágenes de referencia de productos del cliente.
- El tratamiento de resultados que conserva los 10 productos visualmente más similares para cada imagen de entrada.
- Una exportación a Excel con un bloque de resultados por producto, para que el cliente revise las coincidencias en una hoja de cálculo.

## Resultado

El cliente envía un lote de imágenes de ropa y recibe un archivo Excel con las diez coincidencias más cercanas del catálogo para cada una. El servicio funciona sobre Google Cloud y reutiliza la API Product Search en lugar de un modelo entrenado a medida.
